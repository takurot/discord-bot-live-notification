# StreamPulse Bot 導入・利用マニュアル

## 🚀 はじめに
**StreamPulse** は、Twitch配信者のライブ開始を検知し、あなたのDiscordサーバーへ自動でお知らせするBotです。
配信が終了すると、通知メッセージが自動的に「配信終了」状態に更新されるため、チャンネルが埋もれるのを防ぎます。

---

## 📥 導入方法

### 1. Botをサーバーに招待する
管理者から共有された **招待リンク** をクリックしてください。
ブラウザが開いたら、Botを追加したいサーバーを選択し、「認証」ボタンを押します。

※ Botを導入するには、そのサーバーでの「サーバー管理」権限が必要です。

### 2. 通知を受け取るチャンネルの準備
Botが通知を送信するためのテキストチャンネルを用意してください。
専用のチャンネル（例: `#配信通知`）を作るか、既存のチャンネル（`#general` など）を使用することも可能です。
Botがそのチャンネルを見たり書き込んだりできるよう、チャンネルの権限設定を確認してください。

---

## 🎮 コマンドの使い方

すべての操作は `/` (スラッシュ) から始まるコマンドで行います。

### 🔔 配信通知を追加する
指定したTwitchチャンネルの配信が始まったら通知を受け取ります。

**コマンド:**
`/notify add <twitch_url>`

**使用例:**
```
/notify add https://www.twitch.tv/shroud
```
👉 成功すると、「✅ **Shroud** の配信通知設定を追加しました！」と表示されます。
※ 1つのサーバーにつき、最大3枠まで登録できます（Freeプラン）。

### 🗑️ 配信通知を削除する
通知が不要になった配信者をリストから削除します。

**コマンド:**
`/notify remove <streamer_name>`

**使用例:**
```
/notify remove Shroud
```
👉 配信者名はTwitchのユーザー名（英語IDでも表示名でも可）を入力してください。途中で候補が表示されます。

### 📋 登録リストを確認する
現在、このサーバーでどの配信者を監視しているか一覧表示します。

**コマンド:**
`/notify list`

**表示例:**
```
📋 配信通知リスト (1/3)
1. 🎮 Shroud (https://www.twitch.tv/shroud)
```

### 🧪 通知テストを行う
通知のデザインやメンションが正しく動作するか、テスト送信を行います。
（実際の配信開始を待たずに、見た目を確認できます）

**コマンド:**
`/notify test`

### 📊 Botの状態を確認する
Botの稼働状況や、サーバー全体の登録状況を確認します。

**コマンド:**
`/status`

## 💡 よくある質問

**Q. 配信が始まったのに通知が来ません。**
- A. Botは数分おき（約3分間隔）に配信状況をチェックしています。配信開始から通知まで、最大で3分程度のタイムラグが発生する場合があります。

**Q. 通知が来たのに、クリックしたら配信が終わっていました。**
- A. Botは配信終了も検知し、元の通知メッセージを「⚫ 配信終了」という表示に自動更新します。過去の通知ログとしてご確認ください。

**Q. 登録枠（3枠）を増やしたいです。**
- A. 現在はFreeプラン（MVP版）のため、1サーバーにつき3名までとなっています。将来のアップデートで拡張予定です。
